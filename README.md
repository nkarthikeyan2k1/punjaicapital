# Punjai Capitals Sports Club website : https://nkarthikeyan2k1.github.io/punjaicapitals/

Plain HTML, CSS and JavaScript. No framework, no build step.

```
index.html      page markup
css/style.css   all styles
js/main.js      loader, menu, video, registration form
assets/         logos, team photo, Instagram photos (ig/), race reel (video/)
```

## Run locally
Open `index.html`, or serve the folder: `python3 -m http.server 8000` and visit http://localhost:8000.

## Connect the registration form
In `js/main.js`, set `SCRIPT_URL` to your Google Apps Script web app URL. Until then the form runs in demo mode.

## Publish on GitHub Pages
Push this folder to a repo, then Settings → Pages → deploy from the `main` branch, root folder.

Photos in `assets/ig/` come from @punjaicapitals and members' own posts. Get each member's OK before going live.
